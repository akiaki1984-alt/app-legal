行きどき プライバシーポリシー

最終更新日: 2026年8月7日

行きどき（以下「本アプリ」）は、行きたい場所や気になるイベントを保存し、行けるタイミングで思い出すための iOS アプリです。本アプリはアカウント登録が不要で、開発者のサーバーを持ちません。広告や外部の解析 SDK も使用しておらず、開発者が利用者を特定できる情報を収集・保存することはありません。

1. 開発者が収集する情報

ありません。本アプリは開発者のサーバーを持たず、保存した内容・位置情報・利用状況のいずれも開発者に送信されません。

2. 端末内に保存される情報

次の情報がお使いの端末内にのみ保存されます。

・保存したスポットやイベント（名称、ひとこと、住所、緯度経度、日付、料金、メモ、タグ、状態、共有元 URL）
・表紙として選んだ画像
・表示モードや並び順などのアプリ設定
・購入状態

これらはアプリ本体・共有拡張・ウィジェットの間でのみ共有されます（App Group）。iCloud 同期は行いません。アプリを削除すると、これらの情報も端末から削除されます。

3. 位置情報

「ここから◯分」「近い順」などの距離表示のために、アプリの使用中のみ位置情報を利用します。位置情報は端末内での距離計算だけに使い、開発者や第三者へ送信することはありません。許可しない場合でも、距離の表示が出ないだけで、保存・見返し・通知はそのままご利用いただけます。

4. 通信について

本アプリは次の場合に通信を行います。いずれも保存内容を開発者へ送るものではありません。

(a) 共有されたページの読み取り
他のアプリから URL を共有すると、その内容（店名・住所・日付・写真など）を自動で取り込むために、共有された URL のページへ直接アクセスします。この通信は利用者の端末とそのサイトの間で行われ、一般的な Web 閲覧と同様に、そのサイトに IP アドレスなどの接続情報が記録される場合があります。

(b) 住所から地図上の位置を求める処理
ページから住所が取れて緯度経度が取れなかった場合に限り、距離表示のために Apple の位置情報サービスへ当該の住所を送信します。この処理は Apple のプライバシーポリシーに従います。

(c) 地図画像の生成
写真が取得できない場所を保存するとき、表紙として地図の画像を作るために Apple の地図サービスへ当該の座標を送信します。

(d) 購入と復元
App Store との通信は Apple が行います。開発者が決済情報を受け取ることはありません。

5. 写真・スクリーンショットの読み取り

画像を共有して保存する際、そこに写っている文字（イベント名・日付・場所など）を読み取って入力欄に反映します。この文字認識は iOS の機能を使って端末内で完結し、画像や読み取った文字が外部へ送信されることはありません。写真ライブラリ全体へのアクセスは要求しません。

6. 通知

イベントの終了が近づいたときなどにお知らせする通知は、すべて端末内で組み立てられるローカル通知です。外部のプッシュ通知サーバーは使用していません。

7. 外部リンク

保存した場所の住所や共有元をタップすると、地図アプリや Web ブラウザなど外部のアプリが開きます。遷移先での取り扱いは、それぞれのサービスのプライバシーポリシーに従います。

8. 子どものプライバシー

本アプリは、子どもから意図的に個人情報を収集することはありません。そもそも開発者が収集する情報がありません。

9. 本ポリシーの変更

本ポリシーを変更する場合は、本ページを更新し、最終更新日を改めます。
