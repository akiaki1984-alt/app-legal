よくある質問とお問い合わせ

急な強い腫れ、片側だけの腫れ、痛み・赤み、呼吸の異常、長引く症状がある場合は、このアプリの予報を使わず医療機関へご相談ください。

予報はどう決まりますか

起床予定時刻から遡る24時間の記録を見ます。同じ量でも、起床に近い時間の記録ほど強く反映されます。表示は「低め / ふつう / やや高め / 高め」の4段階と、推定の幅、そして信頼度です。数値は目安で、測定値ではありません。

気圧は入っていますか

入れていません。このアプリが扱うむくみとの定量的な関係が十分に確立していないためです。湿度も表示だけで、スコアには入れていません。

「あなた向けの調整」とは

朝の回答が14件たまり、「なし」と「強い側」の両方が揃うと、どの要因があなたの朝と結びつきやすいかを端末の中だけで学習します。反映は最大70%までで、残りは共通の予報のままです。設定からいつでもオフにしたり、学習をやり直せます。

ヘルスケアを許可したくありません

許可しなくても、予報・記録・朝の回答はそのまま使えます。睡眠と歩数が無いぶん、信頼度が控えめになるだけです。

記録を間違えました

保存直後は6秒間「取り消す」が出ます。それ以降は、記録をタップして時刻の変更や削除ができます。

写真は外へ送られますか

送られません。朝の写真は完全に任意で、端末の中だけに保存されます。保存時に撮影日時と位置（EXIF / GPS）を取り除き、iCloud 同期とバックアップの対象からも外しています。顔の判定も採点もしません。

購入について

Pro は買い切りです。同じ Apple ID なら、設定の「購入を復元」から復元できます。購入しなくても、予報・記録・朝の回答・基本のウィジェットは使えます。
